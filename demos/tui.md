# Demo: wglane TUI

**Terminal:** 100x28

## Steps

1. **Open the dashboard**
   `press "wglane tui" Enter`
   `wait 1800`

2. **Expand a continent and move through it**
   `press Enter ArrowDown ArrowDown ArrowDown`
   `wait 600`

3. **Search for a country with /**
   `press / z a`
   `wait 1000`
   `press Enter`

4. **Help overlay**
   `press ?`
   `wait 1800`
   `press Escape`

5. **Quit**
   `press q`
